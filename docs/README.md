# Design history

The specs in [`superpowers/specs/`](superpowers/specs/) record how Switchback was designed,
decision by decision. They were written while the product was called Longhand, and they still
say so: the rename changed the name, not the design. For how Switchback behaves today, read the
skill in [`skills/switchback/`](../skills/switchback/) and the CLI's own `--help`.
